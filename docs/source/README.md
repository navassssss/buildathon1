# Source planning artifacts

Store the team's original mind map export and converted Markdown here. Preserve original inputs as read-only references; put summaries, IDs, and generated splits in separate files.

For each source artifact, record:

- Filename and format.
- Author/team and date, if known.
- Whether it is original, converted, or AI-generated.
- Which version is current.

Example index:

| Artifact | Type | Provenance/date | Status | Notes |
|---|---|---|---|---|
| `<filename>` | mind map / converted Markdown | TBD | Current source / archived | TBD |

The source mind map is the team's planning input. Approved project decisions and feature specs clarify how that input applies to implementation; they do not silently rewrite the preserved source.
