# Feature specifications

Create one file per coherent feature using `FEATURE_SPEC_TEMPLATE.md`. Name files `FEATURE-<short-kebab-name>.md` and give each requirement a stable ID such as `F-<AREA>-001`.

`FEATURE_INDEX.md` maps source mind-map nodes to feature requirements, member owners, priority, and spec files. Proposed AI splits remain proposed until team review. Link to source node IDs rather than copying large source sections.
